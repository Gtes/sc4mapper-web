# `src/lib/sc4mapper`

TypeScript port of the [SC4Mapper-2026](https://github.com/caspervg/SC4Mapper-2026) Python package (QFS, terrain palette, city grid, DBPF save, 16-bit PNG, region ZIP).

Play with these modules on their own — they do not depend on the browser editor. Draw, Stamp, draft, and UI live in `src/tools/` and `src/app/`.
